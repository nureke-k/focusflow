# FocusFlow ⏱️

A minimalist **Pomodoro timer** built with plain HTML, CSS, and JavaScript — no frameworks, no build step. Created for a local hackathon.

## Features

- 🎯 Focus, Short Break, and Long Break modes
- ▶️ Start / Pause / Reset controls
- 📊 Tracks completed sessions
- 🖥️ Live countdown in the browser tab title
- 📱 Responsive, dark-themed UI

## Getting Started

No installation needed. Just open `index.html` in any modern browser:

```bash
# Clone the repo
git clone https://github.com/<your-username>/<your-repo>.git
cd <your-repo>

# Open in your browser (or double-click index.html)
```
